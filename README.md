## 📖 About the Project

**FlexFit** is a full-stack clothing management and e-commerce platform developed to enhance online fashion retail through algorithmic sizing recommendations, virtual closet matching, an AI customer support chatbot, and secure online checkout.

---

## ✨ Core Features

- **📏 Intelligent Size Advisory:** Algorithmic size recommendation engine that matches user body measurements against garment specifications to reduce sizing uncertainty and returns.
- **👗 Virtual Closet Matching:** Interactive outfit pairing and wardrobe management for a tailored shopping experience.
- **🤖 AI-Assisted Customer Support:** Real-time conversational assistant integrated via the **Google Gemini API** to guide users through product discovery, sizing queries, and order support.
- **💳 Virtual Payment Gateway:** End-to-end secure online checkout integration powered by **PayHere**.
